PR RENTAL SERVICES — GITHUB UPLOAD

1. Extract this ZIP.
2. Upload ALL files directly into the GitHub repository root.
3. Do not upload the ZIP itself.
4. Do not put these files inside another folder.
5. index.html must be directly visible in the repository root.
6. All website photos are included as normal image files in the repository root, and the HTML/JS uses root-relative filenames so GitHub Pages can load them reliably.
7. Commit changes.
8. Settings > Pages > Deploy from branch > main > /(root) > Save.
9. Wait for GitHub Pages deployment, then hard-refresh the website.
